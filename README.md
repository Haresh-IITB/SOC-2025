🌟 Summer of Code ’25 Project: Conquering Competitive Programming

Welcome to the official GitHub repository for the Summer of Code ’25 project: Conquering Competitive Programming.

This project is designed to guide you through becoming a proficient competitive programmer — with minimal prerequisites and a well-structured, progressive roadmap.

🛣️ Weekly Roadmap

Week	Topics & Resources
Week 1	Foundations(C++), STL, Sorting and Searching, Time complexity 
Week 2	Stacks, Queue, sets, hash maps 
Week 3	Graphs, BFS, DFS
Week 4	Buffer / Revision Week
Week 5	Dijsktra's Algorithm , Minimum Spanning Trees, Kruskal and Prim Algorithms.

⸻

✅ How to Use This Repository
	1.	Follow the weekly content linked above.
	2.	Practice problems will be shared in each Notion document.
	3.	Try to submit at least 5–7 problems per topic on platforms like Codeforces, CSES, and LeetCode.
